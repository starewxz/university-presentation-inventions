# Publishing the presentation on GitHub Pages

GitHub Pages can host this project because the browser only receives the static
files generated by Vite. GitHub Actions builds those files from the React source
and publishes the `dist` directory automatically; `dist` does not need to be
committed.

## One-time setup

1. Create an empty repository on GitHub. Do not add a README or `.gitignore` there.
2. Add it as a second remote so the existing project remote stays untouched:

   ```bash
   git remote add github https://github.com/USERNAME/REPOSITORY.git
   git push -u github main
   ```

3. On GitHub, open **Settings → Pages** and choose **GitHub Actions** under
   **Build and deployment → Source**.
4. Open the **Actions** tab. The `Deploy presentation to GitHub Pages` workflow
   will build and publish the site. Its deployment summary contains the public URL.

Every later push to `main` rebuilds and republishes the presentation:

```bash
git add .
git commit -m "Update presentation"
git push github main
```

The Vite configuration detects the GitHub repository name during the workflow,
so both `USERNAME.github.io` repositories and project URLs such as
`USERNAME.github.io/REPOSITORY/` get the correct asset paths automatically.
